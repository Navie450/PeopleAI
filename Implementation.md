# 👤 PeopleAI – Employee Feature Roadmap

## 🎯 Goal

Make the **Employee experience personal, useful, and modern**
(so it feels like a *career platform*, not an HR form)

---

## 🧭 Phase 1: Fix Empty Screens

> **Immediate visual & UX improvement**

### Features

* ✅ Proper **Empty States** (illustration + CTA)
* ✅ Employee **My Work Hub (Home Page)**
* ✅ Profile completeness indicator (progress bar)

### Employee Sees

* Welcome message
* Leave balance
* Active goals
* Skills snapshot

### Impact

* App feels alive from day one
* No more blank tables

---

## 🧠 Phase 2: Skills & Growth 

> **Career-focused engagement**

### Features

* Skill management (add/edit skills)
* Skill levels (Beginner → Advanced)
* Progress bars
* Certifications upload

### Employee Sees

* Skill strength overview
* Growth direction

### Impact

* Strong LinkedIn-like value
* High daily interaction potential

---

## 🎯 Phase 3: Goals & Performance 
> **Purpose & motivation**

### Features

* Personal goals (quarterly / yearly)
* Goal status tracking
* Self-assessment notes
* Completed goals history

### Employee Sees

* Clear progress toward goals
* Ownership of performance

---

## 🕒 Phase 4: Timeline-Based Profile 

> **Story of the employee**

### Features

* Career timeline:

  * Joined company
  * Skill added
  * Certification earned
  * Goal completed
  * Promotion (read-only)

### Employee Sees

* Career journey, not static tabs

### Impact

* Modern UX
* Portfolio-ready feature

---

## 🏖 Phase 5: Leave & Availability 

> **Daily usefulness**

### Features

* Leave balance breakdown
* Leave history
* Upcoming leaves
* Simple leave request flow (optional)

### Employee Sees

* Clear time-off visibility

---

## 📈 Feature Priority (Employee)

| Priority       | Feature                   |
| -------------- | ------------------------- |
| 🔥 Must-have   | My Work Hub, Empty States |
| 🚀 High Impact | Skill Tracker             |
| 🎯 Engagement  | Goals                     |
| ✨ Modern UX    | Timeline Profile          |
| 🧩 Utility     | Leave Management          |

---

## 🛠 Recommended Build Order

1. Employee Dashboard (My Work Hub)
2. Skills Module
3. Goals Module
4. Timeline Profile
5. Leave View
